# EDTS Android Guidelines

Mandatory development guidelines for EDTS Android projects. Use these rules when reading, writing, reviewing, or refactoring Kotlin and XML code in View-based or Jetpack Compose projects.

## Installation

Make sure Node.js is installed, then run:

```sh
npx skills add edtsmobile/edts-android-guidelines
```

### Update

```sh
npx skills update -g edts-android-guidelines
```

### Remove

```sh
npx skills remove -g edts-android-guidelines
```

## How to use?

Add this to your AGENTS.md or CLAUDE.md in EDTS Android projects.

```
# EDTS Android Project

Use `edts-android-guidelines` skill.
```
